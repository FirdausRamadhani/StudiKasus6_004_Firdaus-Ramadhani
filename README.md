### Sistem Manajemen Data Toko

Sistem ini adalah program sederhana untuk manajemen data barang dan stok di toko kelontong. User yang mengguanakan program ini bisa melihat barang dan stok yang tersedia dan dapat menambah barang dan stok baru. 

#### Yang ada di dalam program ini

`function/def` ==> Untuk membuat fungsi seperti menu opsi 1 melihat data dan opsi 2 menambah data. digunakan hanya agar terlihat rapi.

`library` ==> `import json` yang paling penting karena dengan ini input yang dimasukkan oleh user akan tersimpan di file .json yang telah dibuat. `import os` digunakan untuk clear saja agar lebih bersih

`if-else` ==> percabangan opsi 1,2, dan 0

`while` ==> perulangan agar menu berjalan terus menerus sampai user ingin keluar.
